ns-rclone

ns-rclone is a private backup tool of NeuroSynergy. Every night it copies encrypted backups of the owner's own websites from the owner's private server to the owner's own Google Drive.

The tool is used only by its owner. It is not offered to the public, and no other users can sign in to it.

Google data used

  • drive.file - to create, read and delete only the backup files that the tool itself has created in the owner's Google Drive. The tool cannot see any other files.

See the Privacy Policy.
