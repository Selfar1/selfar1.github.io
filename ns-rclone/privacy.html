ns-rclone - Privacy Policy

Effective date: 23 November 2026

ns-rclone is a private tool operated by NeuroSynergy for a single user - its owner. This policy explains how it handles Google user data.

What data is accessed

  • OAuth tokens that let the tool store files in the owner's Google Drive.
  • Only the files the tool itself creates there: encrypted backup archives of the owner's websites. Other Drive files are not accessible to the tool (drive.file scope).

How the data is used

Only to upload, verify and rotate (delete old) encrypted backups of the owner's own websites. The tool does not read, analyse or modify any other content of the Drive.

Storage and sharing

  • Tokens are stored only on the owner's private server, with access restricted to the administrator.
  • Backups are encrypted before upload; Google cannot read their contents.
  • Google user data is not sold, shared with third parties, used for advertising, or used to train AI models.

ns-rclone's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. After revocation the stored tokens stop working.
