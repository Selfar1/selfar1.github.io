# selfar1.github.io

Статичний сайт GitHub Pages `https://selfar1.github.io` (публічний репозиторій). Призначення - сторінки для Google Cloud Branding: застосунок YouTube `YTUpload` (`ytupload/`, `ytupload/privacy.html`) і клієнт rclone для бекапу сайтів у Google Drive `ns-rclone` (`ns-rclone/`, `ns-rclone/privacy.html`).

## Контекст

- Правила: C:\AI\knowledge\_rules.md
- Проєкт: C:\AI\knowledge\ventures\server-automation\PROJECT.md

На початку кожної сесії прочитай обидва файли.
Рішення, статус і наступні кроки живуть лише в PROJECT.md. Тут — тільки технічне.

## Стек

- Чистий HTML + `style.css`, без збирання. Публікація - push у `main` (Pages з кореня).
- Файл підтвердження Google Search Console (`google*.html`) - у корені, не видаляти: без нього домен перестане бути підтвердженим.

## Правила роботи з кодом

- Відповідай українською.
- Репозиторій публічний: жодних секретів, пошт, особистих даних.
- Перед великими змінами коротко опиши план і дочекайся згоди.
- Комміт після кожного завершеного кроку, push на GitHub наприкінці сесії.
- Не створюй файлів у C:\AI\knowledge, крім запису в журнал PROJECT.md.

## Завершення сесії

Запропонуй запис для журналу PROJECT.md у форматі з _rules.md (розділ 5), інструмент — `Claude Code`.
Після підтвердження власника допиши його на початок журналу і онови дату «Оновлено».
